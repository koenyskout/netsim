# NetSim

A visual, step-by-step network simulator for teaching MAC, IP, ports, switches, routing and NAT. See [PLAN.md](PLAN.md).

## Development

```
npm install
npm run dev     # local dev server
npm test        # engine tests
npm run build   # production build into dist/
```

Pushing to `main` builds and deploys to GitHub Pages (Pages source must be set to "GitHub Actions").
